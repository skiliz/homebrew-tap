# skiliz/homebrew-tap

Homebrew casks for [ZAP](https://github.com/skiliz/zap), a native macOS menu bar remote for Amazon Fire TV —
a product of Cosmos, open source.

## ZAP

The cask is published with ZAP's first release that is signed with a Developer ID and notarized by Apple.
**It is not available yet.** Once it is:

```sh
brew install --cask skiliz/tap/zap-remote
```

Upgrade with `brew upgrade --cask zap-remote` (your pairing and settings are kept). Remove with
`brew uninstall --cask zap-remote`; add `--zap` to also delete ZAP's pairing and settings
(`~/Library/Application Support/ZAP Remote` and its preferences).

`Casks/zap-remote.rb` is generated by ZAP's `scripts/release.sh` from `templates/zap-remote.rb.in`, using the
real release version and the SHA-256 of the published archive.
