# skiliz/homebrew-tap

Homebrew casks for [ZAP](https://github.com/skiliz/zap), a native macOS menu bar remote for Amazon Fire TV —
a product of Cosmos, open source.

## ZAP

**Not available yet:** the cask is added here when ZAP's first release is published. Then:

```sh
brew install --cask skiliz/tap/zap-remote
```

Requires macOS 14 or later on Apple silicon.

ZAP is free and open source, and its releases are **not signed with an Apple Developer ID and not notarized by
Apple**. Homebrew keeps macOS's normal protection, so the first time you open ZAP macOS blocks it: open it once,
then go to **System Settings → Privacy & Security** and click **Open Anyway**. macOS asks again after each
upgrade. Never turn off Gatekeeper for this.

Upgrade with `brew upgrade --cask skiliz/tap/zap-remote` (your pairing and settings are kept). Remove with
`brew uninstall --cask zap-remote`; add `--zap` to also delete ZAP's pairing and settings
(`~/Library/Application Support/ZAP Remote` and its preferences).

Homebrew 6 and later ask you to trust third-party taps. Installing with the full name above trusts this cask
only.

## Maintainers

`Casks/zap-remote.rb` is generated by ZAP's `scripts/release.sh` from a template in `templates/`
(`zap-remote-adhoc.rb.in` for ad-hoc signed releases, `zap-remote.rb.in` once releases are notarized), with
the real release version and the SHA-256 of the published archive. Never edit those values by hand.
