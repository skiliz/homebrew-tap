# skiliz/homebrew-tap

Homebrew casks for [to.zap](https://github.com/skiliz/tozap), a native macOS menu bar remote for Amazon Fire TV —
a product of Cosmos, open source.

## to.zap

```sh
brew install --cask skiliz/tap/tozap-remote
```

Requires macOS 14 or later on Apple silicon.

to.zap is free and open source, and its releases are **not signed with an Apple Developer ID and not notarized by
Apple**. Homebrew keeps macOS's normal protection, so the first time you open to.zap macOS blocks it: open it once,
then go to **System Settings → Privacy & Security** and click **Open Anyway**. macOS asks again after each
upgrade. Never turn off Gatekeeper for this.

Upgrade with `brew upgrade --cask skiliz/tap/tozap-remote` (your pairing and settings are kept). Remove with
`brew uninstall --cask tozap-remote`; add `--zap` to also delete to.zap's pairing and settings
(`~/Library/Application Support/to.zap` and its preferences).

Homebrew 6 and later ask you to trust third-party taps. Installing with the full name above trusts this cask
only.

## Maintainers

`Casks/tozap-remote.rb` is generated by to.zap's `scripts/release.sh` from a template in `templates/`
(`tozap-remote-adhoc.rb.in` for ad-hoc signed releases, `tozap-remote.rb.in` once releases are notarized), with
the real release version and the SHA-256 of the published archive. Never edit those values by hand.
